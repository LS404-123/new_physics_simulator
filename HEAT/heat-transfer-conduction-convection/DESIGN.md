# 傳導與對流模擬器設計

## 理解摘要

- 對象：難以在腦中想像微觀熱傳過程的 HKDSE 學生。
- 任務：在同一頁以按鈕切換「傳導」和「對流」兩個獨立模擬。
- 傳導預測：加熱左端後，哪一列粒子會最先加劇振動？
- 傳導證據：固定晶格粒子水平振動、由左至右逐粒推撞、能量連線及同步溫度—位置曲線。
- 對流預測：加熱容器底部後，暖流會沿哪條路徑循環？
- 對流證據：等質量流體粒子的疏密、上下密度取樣值、密度刻度及連續循環流線。
- 非目標：不模擬金屬自由電子、真實分子動力學或完整計算流體力學。

## 假設

- 純前端、離線、單人課堂使用，不儲存資料。
- 畫布固定為 1140×768 CSS px、effective scale 1，基準 viewport 不可捲動。
- 傳導使用 102 個粒子，排列成 17×6 固定晶格；水平中心距 26 px，左右端保持在 169–585 px。
- 對流使用 180 個等質量流體小團；每個圓點不是單一分子。
- 模擬只保留開始／暫停、加熱強度、動畫速度、慢動作及重設等直接需要的控制。
- 正式方程及物理符號使用本機 KaTeX。

## 最終設計

### 單頁結構

- 頂部：標題、傳導／對流切換按鈕、返回目錄。
- 中部：先預測區、主要 Canvas 物理區、同步證據區。
- 底部：模式相關控制、圖例、重設。
- 切換模式時保留各自獨立狀態；重設只重設目前模式。

### 傳導

- 粒子只在晶格平衡位置附近振動，不隨熱由左移到右。
- 左端加熱只直接驅動第一列；右邊粒子保持靜止，直至左粒子接近至推撞門檻。
- 推撞以一維等質量速度交換近似，令右粒子取得向右速度，再推撞下一粒。各行加入少量時間差，避免六行完全同步。
- 粒子接近期間按溫差交換能量，推撞瞬間顯示短暫黃色連線及向右箭嘴：

\[
\Delta Q_{i\to i+1}\propto(T_i-T_{i+1})\Delta t
\]

- 溫度—位置曲線由每一晶格列的平均溫度繪製，與粒子顏色及振動驅動共用同一狀態。
- 粒子只沿左右移動，避免把固體晶格誤畫成自由飛行氣體。

### 對流

- 底部加熱使流體温度上升及密度下降；在重力場中產生浮力上升，冷而密的流體下沉並形成循環。
- 密度使用線性熱膨脹近似：

\[
\rho=\rho_0[1-\beta(T-T_0)]
\]

- 局部密度由三項同步證據呈現：等質量粒子間距、上下取樣框的密度數值、獨立深淺密度刻度。
- 温度仍以藍至紅表示，密度不再共用顏色，避免混淆兩個物理量。
- 粒子、流線箭嘴、温度、密度及流速全部取自同一模擬狀態。

## 決策紀錄

| 決定 | 曾考慮方案 | 理由 |
|---|---|---|
| 原生 Canvas 配合 HTML 控制及 KaTeX | SVG、大量 CSS 動畫 | Canvas 適合持續更新大量粒子；不需要前端框架。 |
| 一頁雙模式切換 | 兩個分開頁面 | 符合使用者要求，方便課堂直接比較兩種熱傳。 |
| 傳導使用固定晶格及逐粒推撞 | 連續耦合振子、粒子自由移動、只用色帶 | 清楚呈現「左粒子推動右粒子」的教學因果，同時保留物質不遷移。 |
| 温度—位置曲線 | 只顯示粒子顏色 | 提供可量度的宏觀證據，並展示熱前沿隨時間推進。 |
| 對流用粒子疏密加密度數值 | 只用另一套顏色 | 不與温度色階混淆，亦能直接連結密度與流動。 |
| 使用教學近似模型 | 真實分子動力學或 CFD | 目標是概念可視化；完整模型會增加複雜度而不改善本課重點。 |

## 對流雙子模式擴充設計（已實作）

### 理解摘要

- 保留最外層「傳導／對流」切換；對流內新增「初始密度差」及「底部持續加熱」兩個獨立子模式。
- 「初始密度差」由底部 60°C 向上連續降至頂部 20°C，開始後沒有持續熱源。
- 底層暖水的微觀熱運動較劇烈、粒子間距較疏；頂層冷水粒子較密。
- 暖水整體上升由密度差配合重力所產生的浮力驅動，不把較快的微觀熱運動當成上升原因。
- 暖冷流體逐漸混合；溫度及密度趨向均勻後，對流自然減弱並停止。
- 預測題為「哪一層流體密度最高？」；正確答案是頂層，主要證據是相同大小粒子的可見疏密差。
- 「底部持續加熱」完整保留現有加熱強度、預測題、密度取樣及圖表。

### 假設及非目標

- 流速由密度差控制，但畫面時間不宣稱等同現實秒數；保留速度及慢動作控制作課堂觀察。
- 粒子間距的密度差作教學式放大，物理密度仍使用既有熱膨脹關係計算。
- 固定 1140×768 CSS px、離線、單一使用者、約 60 fps、沒有資料儲存或傳送，亦不加入新依賴。
- 重設及模式切換必須可重現相同初始狀態。
- 不建立 CFD、真實分子動力學或可作定量預測的水流模型。

### 畫面及操作

- 進入對流後顯示兩個緊湊子模式按鈕；兩個子模式各自保存粒子及播放狀態，切換時不重設。
- 「初始密度差」的主容器以相同半徑粒子顯示密度：底層粒子較少、間距較闊，越向上粒子越密。
- 主容器只顯示粒子，不疊加頂／中／底取樣框或白色流向箭嘴；右側同步放大三區的實際粒子分佈，不以密度數字、粒子大小或另一套顏色暗示答案。
- 第一子模式隱藏加熱強度控制，保留開始／暫停、動畫速度、慢動作及重設。
- `prefers-reduced-motion` 下不自動播放，沿用現有操作方式。

### 物理狀態及更新順序

- 每粒粒子保存 `x`、`y`、`temperature`、`density` 及 `velocity`。初始溫度以畫面頂部 `y = 0`、底部 `y = 1` 定義：

\[
T(y)=20+40y
\]

- 密度繼續使用：

\[
\rho=\rho_0[1-\beta(T-T_0)]
\]

- 每個動畫步驟依次更新：微觀熱運動、由密度差驅動的宏觀循環、短程粒子間距修正、局部對稱熱交換。
- 微觀熱運動只形成圍繞實際流體位置的繪圖偏移；溫度越高，偏移變化越快，但不累積成整體漂移。
- 宏觀流場沿用中央上升、頂部向外、兩側下降及底部補位的循環；速度幅度由當前最大與最小密度差決定。
- 暖而低密度粒子的目標間距較大，冷而高密度粒子的目標間距較小；短程修正設上限，避免重疊、穿越邊界或形成大空洞。
- 鄰近粒子以成對、等量反向的溫度改變交換能量，令無熱源模式的總熱量守恆。混合令溫度變異、密度差及宏觀流速同步下降。

### 驗收及最小檢查

- 初始頂層為 20°C、底層為 60°C，且頂層密度高於底層。
- 所有粒子半徑相同；相同面積內頂層粒子數目多於底層。
- 熱粒子的微觀運動幅度大於冷粒子，但微觀偏移不造成宏觀漂移。
- 零密度差時宏觀流速為零；較大密度差產生較大流速。
- 無熱源混合前後總熱量守恆，溫度變異持續下降；接近均溫時宏觀對流停止。
- 慢動作同步減慢熱運動、流體移動及混合。
- 切換子模式會保存各自狀態，重設只重設目前子模式，而且結果可重現。
- 原有底部持續加熱模式的物理檢查繼續通過。
- 固定 1140×768、無捲動、子模式切換、取樣區、控制及重設須通過 In-App Browser 驗收。

| 兩個子模式自由切換並保存狀態 | 自動順序播放、下一階段按鈕 | 方便教師反覆比較兩種起始條件。 |

### 初始密度差自然流動修正（已實作）

- 答對分層模式預測後只揭示靜止的粒子疏密分佈；使用者須另按「開始觀察」才開始更新粒子。
- 分層模式不再使用固定中央上升、兩側下降的 `convectionVelocity()` 流場。
- 每次重設在既有 20–60°C 垂直梯度加入不同、肉眼幾乎不可見的隨機溫度擾動；擾動總和校正至接近零，避免改變整體總熱量。
- 所有粒子的初始宏觀速度為零。開始後，低於平均密度的粒子獲得向上浮力加速度，高於平均密度的粒子向下。
- 現有短程粒子間距修正負責排開鄰近流體，形成橫向移動及補位，不預設熱柱位置或循環中心。
- 以粒子的垂直排序加入液體體積壓力修正，避免冷暖層相遇後全部擠成中央薄層；修正只維持液體填滿容器，不指定哪一粒子上升或下降。
- 粒子速度跨幀保存，並受阻力、最高速度及容器邊界回彈限制。局部守恆熱交換令密度差下降後，浮力及流速逐漸消失。
- 隨機擾動只用於打破完全水平對稱；初始畫面仍須清楚呈現頂層較密、底層較疏。
- 「底部持續加熱」維持現有固定循環場及操作，不受此修正影響。

| 決定 | 曾考慮方案 | 理由 |
|---|---|---|
| 預測後先靜止揭示證據 | 答對後自動播放 | 讓教師先指出頂密底疏，再由學生主動開始觀察。 |
| 使用局部浮力粒子模型 | 二維網格流體、隨機預設循環中心 | 讓上升位置由密度狀態形成，同時維持現有模型規模及最少改動。 |
| 每次使用不同微小擾動 | 固定擾動、完全無擾動 | 展示熱柱位置不是預設；完全對稱模型則可能無法自行開始流動。 |
| 擾動不可見且近似零總和 | 顯示明顯暖點／冷點 | 保持原有垂直密度證據清晰，亦避免每次重設改變總熱量。 |

最小檢查驗證：暖粒子向上、冷粒子向下、相同密度沒有浮力、兩次重設的微擾不同、無熱源混合總熱量守恆、暖粒子能穿過冷層、混合後粒子仍填滿大部分容器，以及分層模式答對預測後仍保持暫停。

### 雙圓筒隔板模式修訂（已實作）

本節取代上述單一大容器的初始密度差流動設計。

#### 最終效果

- 初始密度差模式改成上下兩個相同大小、完全裝滿水的 2D 圓筒；上筒為 20°C 冷水，下筒為 60°C 熱水。
- 中間全闊隔板在預測及證據揭示期間保持關閉。使用者按「開始觀察」後，隔板先向右完全抽走，流體才開始交換。
- 暖水因密度較低形成局部上升羽流；凍水在其他位置向下補位。流動須保持兩筒充滿，不可整層同時下墜或擠成中央薄層。
- 流動期間以守恆熱交換逐漸縮小溫差；兩筒平均溫度相同後，流動自然停止。
- 主容器只顯示相同大小粒子、溫度顏色、兩個圓筒及隔板，不顯示三層取樣框或白色流向箭嘴。
- 粒子疏密作清楚標示的教學視覺放大；密度方向及流動因果保持正確，動畫時間不宣稱等同現實秒數。
- 底部持續加熱模式維持現有行為。

#### 實作決定

- 使用由溫差控制、每次重設改變位置的無散度雙向羽流場，而不加入完整 CFD 或新依賴。向上及向下流量成對，避免流體憑空壓縮或產生空洞。
- 粒子只跟隨同一羽流速度場移動；短程間距修正維持液體填滿容器，成對熱交換保存總熱量。
- 隔板位置加入獨立開啟進度；開啟進度未完成時流體時間保持為零。
- 右側證據改為上下兩筒平均溫度及真實平均密度，不再顯示頂／中／底三區取樣圖。

| 決定 | 曾考慮方案 | 理由 |
|---|---|---|
| 雙圓筒加可抽走隔板 | 單一大容器直接開始流動 | 清楚分隔初始狀態與密度驅動的交換流動。 |
| 成對無散度羽流 | 每粒子獨立浮力、完整網格 CFD | 避免整層下墜，同時以最少複雜度呈現暖升冷沉及補位。 |
| 主容器只顯示粒子 | 取樣框、流向箭嘴 | 減少遮擋，讓學生直接觀察兩團水交換位置。 |
| 真實密度計算、疏密視覺放大 | 完全按真實 1.5% 粒子差 | 保留物理數值，同時令疏密差可見。 |

最小檢查須驗證：隔板關閉時粒子不流動；隔板完全移走後才開始交換；暖水重心上升、冷水重心下降；向上及向下流量成對；無熱源總熱量守恆；兩筒平均溫差下降至接近零；相同初溫不產生流動；底部持續加熱模式回歸通過。

## 風險及限制

- 真實固體傳導不需要原子像硬球般逐次碰撞；本模型刻意誇大成接近門檻、等質量推撞及接近期間傳熱，只作教學因果可視化。
- 金屬還有自由電子傳熱，本模擬不涵蓋該機制。
- 密度差本身不保證產生對流；畫面必須同時呈現重力方向及浮力。
- 對流流場是穩定的教學模型，不用作定量預測真實流體速度。
