# 溫度計校準與斜率模擬器設計

## 理解摘要

- 對象：尚未理解斜率寫法及計算的 HKDSE 學生。
- 任務：由兩個固定點建立液柱高度與溫度的線性關係。
- 預測：已知液柱在 \(0\,^{\circ}\mathrm{C}\) 為 2 cm、在 \(100\,^{\circ}\mathrm{C}\) 為 22 cm，預測 \(50\,^{\circ}\mathrm{C}\) 時的高度及算法。
- 證據：同一畫面同步顯示液柱、\((T,h)\) 點、校準直線、\(\Delta h\) 與 \(\Delta T\) 三角形。
- 概念改變：斜率是溫度改變時液柱高度的改變率，即 \(\Delta h/\Delta T\)。
- 控制：目標溫度 \(T\)、低固定點高度 \(h_0\)、高固定點高度 \(h_{100}\)。
- 非目標：不模擬熱傳、液體膨脹過程、非線性溫標或量度誤差。

## 假設

- 兩固定點溫度固定為 \(0\,^{\circ}\mathrm{C}\) 與 \(100\,^{\circ}\mathrm{C}\)。
- 液柱高度與溫度在兩固定點之間呈線性關係。
- 模擬器由教師在單一裝置操作，不儲存資料，也不使用生成式 AI。
- 畫布只以 1140×768 CSS px、effective scale 1 呈現。

## 決策紀錄

| 決定 | 曾考慮方案 | 理由 |
|---|---|---|
| 採用一個整合 SVG | 分開的溫度計及坐標圖 | 共用垂直高度尺度，水平虛線可直接連接液柱頂端與圖點。 |
| 採用三階段揭示 | 首屏顯示全部公式 | 保留「先預測、後觀察」的認知次序。 |
| 只設三個滑桿 | 加入固定點溫度、動畫速度等控制 | 三個控制已足以展示截距、斜率及插值，其他控制會分散焦點。 |
| 使用原生 HTML、CSS、JavaScript | 加入前端框架 | 單頁確定性模擬不需要框架。 |

## 視覺方向

- 主題：物理實驗室的透明方格校準紙。
- 色彩：深藍墨 `#13293D`、紙藍 `#EAF4F8`、液柱紅 `#E24A3B`、證據黃 `#F4B942`、青綠 `#168C8C`。
- 字體：標題用明體、正文用微軟正黑體、數據用 Consolas。
- 招牌元素：溫度計和坐標圖共用同一條高度基準，液柱頂端以水平虛線直接接到 \((T,h)\) 點。

## 教師使用次序

1. 先只顯示兩固定點，請學生獨立預測 \(T=50\,^{\circ}\mathrm{C}\) 時的液柱高度及算法。
2. 按「顯示校準直線」，追問橫軸、縱軸各是哪個物理量，以及為何兩點能決定直線。
3. 按「拆解斜率」，沿黃色三角形辨認 \(\Delta h\) 與 \(\Delta T\)，再寫成 \(m=\Delta h/\Delta T\)。
4. 中段討論：「若只增大 \(h_{100}\)，直線、液柱及每攝氏度的高度改變會怎樣？」
5. 按「開始探索」，依次只改一個滑桿，要求學生先說預測再觀察。
6. 結尾題一：為甚麼斜率單位是 \(\mathrm{cm\,{}^{\circ}C^{-1}}\)？
7. 結尾題二：若 \(h_0=4\ \mathrm{cm}\)、\(h_{100}=29\ \mathrm{cm}\)，求 \(T=60\,^{\circ}\mathrm{C}\) 時的液柱高度。

## 物理模型及限制

\[
m=\frac{h_{100}-h_0}{100-0},\qquad h(T)=h_0+mT
\]

- 有效範圍：\(0\leq T\leq100\,^{\circ}\mathrm{C}\)、\(0\leq h\leq100\ \mathrm{cm}\)。
- 低固定點高度為 0–9 cm，高固定點高度為 10–100 cm，因此斜率保持正值。
- 不模擬玻璃膨脹、視差、液柱截面變化或液體非線性膨脹。

## 驗收紀錄

- 工具：Codex In-App Browser。
- 基準 viewport：1140×768；根畫布 bounding box：\((0,0,1140,768)\)；effective scale：1。
- 較大 viewport：1440×900 / 1920×1065；根畫布仍為 1140×768，水平與垂直絕對雙向居中，effective scale 1。
- 較小 viewport：900×700；根畫布仍為 1140×768，不縮放、不重排，effective scale 1。
- 基準畫面：沒有水平或垂直捲動；公式、圖軸、標籤及控制項沒有溢出。
- 流程：預測、顯示直線、拆解斜率、自由探索、三個滑桿、模型假設及重設均已實際操作。
- 同步證據：預設值（\(h_0=2\ \mathrm{cm}, h_{100}=62\ \mathrm{cm}, T=50\,^{\circ}\mathrm{C}\)）下液柱頂端、水平連線及 \((T,h)\) 點的 SVG \(y\) 座標同為 269。
- 點尺寸精緻化：坐標圖上的點半徑縮小為 `r="5"`（固定點）與 `r="5.5"`（當前點），描邊設定為 2.5px，確保視覺精確與清晰。
- 初始高固定點：預設 \(h_{100}\) 設為 62 cm（斜率 \(m=0.6\ \mathrm{cm\,{}^{\circ}C^{-1}}\)）。
- 邊界：\(h_0=9\ \mathrm{cm}\)、\(h_{100}=10\ \mathrm{cm}\) 時，斜率為 \(0.01\ \mathrm{cm\,{}^{\circ}C^{-1}}\)；\(h_{100}=100\ \mathrm{cm}\) 時，斜率為 \(0.98\ \mathrm{cm\,{}^{\circ}C^{-1}}\)（\(h_0=2\)）。
- 重繪驗收：溫度計改為無縫單一玻璃管 SVG 路徑（消除感溫泡內部重疊黑線與底部內縮，加入高光反射與毛細內孔底色）。
- 對稱佈局：「溫度計 + 坐標圖」組合整體置中（溫度計 centered at X=300px，校準圖區間 X=450–750px，組合幾何中心維護在畫布正中央 X=550px）；斜率卡片解耦配置於右側 X=840–1120px，確保預測階段與探索階段均完美居中。
- Y軸防遮蔽：\(h/\mathrm{cm}\) 位在 `left: 478px; top: 40px`，獨立於 Y 軸頂部箭頭（X=450px）與「校準坐標圖」標籤，無重疊遮擋。
- 局部斜率三角形：在直線中央選取代表性局部區間（\(T_1 = 20\,^{\circ}\mathrm{C}\) 至 \(T_2 = 70\,^{\circ}\mathrm{C}\)）繪製直角三角形，展示任選局部區段求斜率之教學效果；\(\Delta h\) 標籤定位於垂直邊右側（\(X = x_2 + 8\text{ px}\)），\(\Delta T\) 標籤定位於水平邊下方（\(Y = y_1 + 6\text{ px}\)）。
- 水銀色彩純淨分層：將玻璃背景（glass-bg）置於底層、純色水銀置於中層、玻璃邊框（glass 描邊）置於頂層，徹底消除覆蓋在水銀前方的半透明霧面濾鏡感，色彩純淨飽和。
- 坐標標籤避讓斜線：低固定點 \((0, h_0)\) 定位於點左上方（\(X = x_0 - 10\text{ px}\), `text-anchor="end"`），高固定點 \((100, h_{100})\) 定位於點右上方（\(X = x_{100} + 10\text{ px}\), `text-anchor="start"`），當前探索點置於左上方（\(X = x - 12\text{ px}\), `text-anchor="end"`），確保斜線永遠不會穿透標籤文字與白色襯底。
- 平面格線簡約化：移除坐標圖內部的滿版網格線，保留 X/Y 軸 6px 短刻度線與數值標籤，畫面乾淨開闊。
- 導引線對齊：紅色水平導引虛線（`#heightGuide`）起點精確對齊溫度計右管壁（\(X = 316\text{ px}\)），無縫連接液柱頂端至當前坐標點 \((T, h)\)。
- LaTeX：KaTeX 從本機資料夾載入；沒有外部資源、原始 LaTeX 標記或瀏覽器錯誤。
- Runnable check：`node physics-check.js` 通過 \(h_{100}=62\ \mathrm{cm}\) 及 100 cm 上限在內的固定點、斜率及線性插值測試。
- 驗收狀態：完整互動驗收。
